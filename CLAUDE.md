# reviews-analyzer

Разбирает отзывы покупателей через GigaChat: тон и темы каждого отзыва, сводка по жалобам и примеры, результат в Excel.

## Структура

- `analyze_reviews.py` — отзывы уходят в модель пачками по `BATCH` штук с ответом в JSON. Темы задаются списком `TOPICS` в начале файла. Битый JSON повторяется до трёх раз, неотвеченный отзыв получает тему «Другое».
- `data/` — 300 отзывов из открытого датасета RuReviews (Apache 2.0), источник указан в `data/README.md`.
- `examples/` — готовый разбор.
- `tests/test_analyzer.py` — весь конвейер с подменённым ответом модели, без сети.

## Команды

```
pip install -r requirements.txt
cp .env.example .env
python analyze_reviews.py data/отзывы_пример.csv
pytest
```

## Правила

- Модель может выбирать темы только из `TOPICS`, ответ всегда проверяется.
- Функция запроса к модели передаётся параметром `ask`, поэтому тесты не ходят в сеть. Сохранять эту возможность.
- Чужие выгрузки отзывов не коммитить: в них бывают персональные данные.
